# Готовые файлы для переноса

Здесь лежит то, что нельзя забрать из исходников напрямую, потому что оно
создаётся на сборке и в историю не попадает (`dist/` в `.gitignore`).

## `scene/` — десять картинок, по две ширины каждая

Растрированные сцены: рабочее место, площадка, тома, чертёж, журнал работ
и четыре типа объектов. WebP, качество 82.

| Файл | Что на нём | Размер оригинала |
|---|---|---|
| `hero-*.webp` | Рабочее место инженера ПТО: план на мониторе, акт со штампом, тома | 1440×1240 |
| `komanda-*.webp` | То же место с двумя мониторами: план и ведомость | 1440×1240 |
| `ploshchadka-*.webp` | Площадка: башенный кран, монолитный каркас, ограждение, бытовки | 2100×900 |
| `komplekt-*.webp` | Стопка сданных томов, раскрытый титул со штампом приёмки | 1440×1240 |
| `razbor-*.webp` | Чертёж на столе с пометками, линейка, карандаш | 1440×1240 |
| `vedenie-*.webp` | Раскрытый общий журнал работ, ручка, каска | 1440×1240 |
| `obekt-dom-pravosudiya-*.webp` | Общественное здание с колоннадой | 1600×1000 |
| `obekt-vdnh-*.webp` | Павильон с куполом, крыло в лесах | 1600×1000 |
| `obekt-port-holmsk-*.webp` | Причал с портальным краном и судном | 1600×1000 |
| `obekt-dmitrov-*.webp` | Производственный корпус с воротами и рампой | 1600×1000 |

Суффикс — ширина: `-900` для телефона, `-1800` для десктопа и плотных экранов.

```html
<img src="/scene/hero-1800.webp"
     srcset="/scene/hero-900.webp 900w, /scene/hero-1800.webp 1800w"
     sizes="(max-width: 980px) 92vw, 42vw"
     width="1440" height="1240" loading="lazy" decoding="async"
     alt="Иллюстрация: рабочее место инженера ПТО — план на мониторе, акт со штампом приёмки, тома">
```

**Описания (`alt`) обязаны начинаться со слова «иллюстрация».** Сцены нарисованы,
а не сняты, и на карточках объектов показывают тип объекта, а не сам объект.
Выдавать рисунок за снимок конкретного здания нельзя. Готовые описания —
в `src/data/photos.ts`.

Исходники сцен — `src/lib/scenes.ts`, растеризация — `src/pages/scene/[...slug].webp.ts`.
Если понадобится другая ширина или пропорция, менять там.
