## 1. Карточка в Яндекс.Бизнесе

Для локальной услуги это влияет на заявки сильнее любой внутренней оптимизации: карточка
показывается в поиске и на Картах, а отзывы в ней читают до перехода на сайт.

**Где:** `yandex.ru/sprav` → «Добавить организацию».

## 2. Яндекс.Метрика

Счётчик создаётся в вашем аккаунте — на сайте всё готово к нему заранее.

1. `metrika.yandex.ru` → «Добавить счётчик», домен `pro-pto.com`, включить **вебвизор**
   и **карту скроллинга**.
2. Взять номер счётчика (8 цифр) и вписать в `src/data/site.ts`:
   ```ts
   analytics: { yandexMetrika: '12345678', ... }
   ```
   Больше ничего подключать не нужно: пока поле пустое, счётчик не грузится вообще.
3. В интерфейсе Метрики завести восемь целей типа «JavaScript-событие». Идентификаторы уже
   отправляются из кода:

   | Цель | Когда срабатывает |
   |---|---|
   | `form_send` | отправка заявки или заказа звонка |
   | `checklist_send` | отправка формы чек-листа |
   | `tel` | клик по телефону (заработает, когда появится номер) |
   | `tg` | клик по Telegram |
   | `mail` | клик по почте |
   | `calc_use` | первое взаимодействие с калькулятором |
   | `scroll_75` | прокрутка до 75% страницы |
   | `popup_show` | показ всплывающего окна |

Без этого вы не узнаете, какая из семи услуг приносит заявки, — а это первое, что нужно
для рекламы.

## 3. Вебмастер и Search Console

1. `webmaster.yandex.ru` → добавить `pro-pto.com` → способ проверки **метатег** → скопировать
   значение `content` и вписать в `src/data/site.ts`:
   ```ts
   verify: { yandex: 'значение_из_вебмастера', google: '' }
   ```
   Пока поле пустое, метатег не выводится.
2. Пересобрать и выложить, нажать «Проверить» в Вебмастере.
3. Отдать карту сайта: `https://pro-pto.com/sitemap-index.xml`.
4. **Задать регион** — «Информация о сайте» → «Регион»: Москва и Московская область. Для домена
   в зоне `.com` регион не определяется автоматически, и без этого шага сайт не участвует
   в региональной выдаче как следует.
5. То же для Google Search Console, поле `verify.google`.

## 4. Проверки на боевом домене

Делаются только после выкладки, из моего окружения сеть закрыта:

- **PageSpeed Insights** — `pagespeed.web.dev`, проверить главную и `/ceny`.
- **Валидатор микроразметки Яндекса** — `webmaster.yandex.ru/tools/microtest`, проверить главную,
  посадочную услуги и статью.
- **Rich Results Test** — `search.google.com/test/rich-results`, там же.
- **W3C** — `validator.w3.org`. Локально `html-validate` даёт ноль ошибок, но проверить на боевом
  адресе стоит.
- **Safari и Яндекс.Браузер** — открыть главную, `/ceny` и форму. В моём окружении доступен только
  Chromium, поэтому этот пункт критериев приёмки закрыть локально нельзя.

## Что ещё ждёт ваших данных

- **Телефон.** Пока `site.phone` пуст, сайт нигде не показывает номер и не предлагает позвонить.
  Появится симка — впишите номер в двух форматах (`+79161234567` и `+7 916 123-45-67`), и он
  вернётся в шапку, подвал, полосу связи, формы и микроразметку сам.
- **Реквизиты.** ИНН и ОГРН подставятся в подвал и в политику конфиденциальности.
- **Приёмник заявок.** `formEndpoint` — пока форма проверяет, маскирует и показывает благодарность,
  но заявка никуда не уходит. Требования к приёмнику — в `README.md`.
- **Фотографии.** Десять мест размечены, сейчас в них нарисованные сцены. Свой снимок площадки
  или сданного комплекта сильнее любой графики: положите файл в `src/assets/foto/` под именем
  места — список в `src/assets/foto/README.md`.
